# Segurança

- Nunca versione o arquivo `.env`.
- Utilize um usuário MySQL com apenas as permissões necessárias.
- Não utilize dados pessoais reais em demonstrações públicas.
- Mantenha o MySQL atualizado e restrito à rede apropriada.

Falhas relacionadas ao repositório podem ser comunicadas diretamente ao autor pelo perfil indicado no README.
